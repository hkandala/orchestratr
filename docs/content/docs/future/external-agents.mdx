## What orcr does now

orcr controls the agents it started. An agent started by a person in their own terminal, or
by another tool, is invisible to orcr.

## What people would want

Two things. One is easy and one is not.

### Reading

Show the conversations of agents that orcr did not start. List them, read their transcripts,
and report their state.

This is close to free. Transcript reading is already backend independent, and orcr already
converts four transcript formats into one shape. What is missing is discovery: finding
transcripts on disk without a record of having created them, and deciding which working
directory each belongs to.

One rule must survive that work. Never derive a working directory from a transcript path.
Every kind mangles the directory into its path, and the mangling is lossy. Two different
directories can produce the same path segment.

### Driving

Send messages to, interrupt, or stop an agent that orcr did not start.

This is not close to free, and it is where the risk is.

## Why driving an external agent is different

An agent that orcr started has known properties. orcr chose its flags, so it knows
permissions are bypassed. orcr cleared its startup screens, so it knows the agent reached a
usable state. orcr placed it in a pane it owns.

None of that holds for an external agent. It can wait on a permission prompt that orcr's
launch flags remove. It can be in a mode orcr does not recognize. Typing into it can answer a
question that a person was about to answer differently.

The failure is silent. A dialog consumes a message sent into it. The Enter key answers the
dialog. Nothing reports an error.

## What must be decided first

- Whether reading ships separately from driving. It should.
- How an external agent is discovered, and how orcr decides which backend pane, if any, it
  occupies.
- Whether orcr refuses to drive an external agent by default, and what makes it willing.
- What `orcr agent list` shows, and how a caller tells the two populations apart. A field is
  needed, and it should be a property of the agent rather than a separate command.
